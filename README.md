**MTGPLA**

MTGPLA is a hybrid framework integrating multimodal and interaction features for accurate protein-ligand affinity prediction.
It performs better on PDBbind 2016 and PDBbind 2013 datasets than state-of-the-art models,enhancing the efficiency and accuracy 
of drug discovery.

**Dependency**

The directory of Python packages required for the dependencies should be placed in a requirements file.
